# Social Media Content Blockers
Block reels and shorts on web versions of the Instagram and YouTube apps.

## iOS Installation

These rules run in [wBlock](https://github.com/0xCUB3/wBlock), a free, open-source content blocker for Safari.

### 1. Install wBlock

1. Install [wBlock from the App Store](https://apps.apple.com/us/app/wblock/id6746388723).
2. Open wBlock and follow its first-launch steps to turn on its Safari extensions.

### 2. Import the rules via URL

1. In wBlock, tap the + button in the toolbar to add a filter list.
2. Enter this URL:

   ```
   https://raw.githubusercontent.com/jotamunz/social-media-content-blockers/main/instagram-reels.txt
   ```

3. Confirm the addition and tap **Apply** to update.
4. Repeat for the YouTube shorts rules with its respective url.

### 3. Add web app to home screen

1. Open Instagram in Safari and log in.
2. Tap **Share → Add to Home Screen** to use Instagram as a web app.
